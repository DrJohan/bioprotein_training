# Phosphor icons

Original regular-weight SVGs from [Phosphor Icons Core](https://github.com/phosphor-icons/core), pinned to commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.

Copyright Phosphor Icons. Distributed under the MIT licence in `LICENSE.txt`.

The SVG files are unchanged. Their paths are embedded in `index.html` with decorative accessibility attributes; CSS applies the Klinik Inocare blue through `currentColor`. Icons accompany text and are used for learning outcomes, healing phases and procedure-room preparation. Inline SVG keeps the icons crisp in browser and PDF views.
